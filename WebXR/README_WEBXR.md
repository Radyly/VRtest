# Quick WebXR test on Meta Quest 3

## Test on PC first

Open a terminal in this `WebXR` folder:

```bash
python3 -m http.server 8000
```

Open `http://localhost:8000` in your desktop browser. A-Frame is loaded from `https://aframe.io/releases/1.8.0/aframe.min.js`, so the browser must have Internet access.

- Walk: `W`, `A`, `S`, `D`
- Look: click inside the 3D scene and move mouse
- Unlock mouse: Esc
- Visit zones: press keys `1`, `2`, `3`, `4`, `5` or use the overlay buttons
- Change colors: use the world-style dropdown. Menu toggle is at upper right (`H` shortcut).

## Use Meta Quest 3 in VR

**WebXR normally requires HTTPS from the headset.** Avoid typing a PC-only `localhost:8000` address in Quest Browser: on Quest, localhost refers to the headset, not the laptop.

### Option: Free GitHub Pages

1. Create a GitHub repository, for example `aupp-etl-metaverse`.
2. Upload **all contents of the `WebXR` folder** at the repository root, including `index.html`.
3. Go to repository **Settings > Pages**. Select **Deploy from a branch**, branch `main`, folder `/ (root)` and Save.
4. Wait for GitHub Pages to show your own `https://<username>.github.io/aupp-etl-metaverse/` URL.
5. On Quest 3, open that HTTPS address in **Meta Quest Browser**. After the page loads, select **Enter VR**.

### Quest controls

- Left thumbstick: move through the rooms
- Right thumbstick: snap turn
- Right A: next tour destination
- Right B: previous destination
- Right controller trigger pointed at the pad: jump to its tour destination
- Physical head movement: look around

Input mapping is a best-effort demonstration and should be checked against your particular Quest controller firmware and browser. This is not the same as a compiled offline APK.

## Practical notes

You can freely customize the floor plan, lighting palette and exhibit rooms by editing `index.html`.
The text/geometry are generated by JavaScript in the `buildWorld()` function.
A-Frame's built-in components are used for headset/head tracking and controller ray selection.

For long-term public delivery, bundle a trusted, tested copy of the A-Frame runtime locally or use a fixed CDN library with appropriate supply-chain review. This demonstration pins the A-Frame release URL; Internet is required.

Reference: https://developers.meta.com/vr/documentation/web/port-vr-xr/ (HTTPS requirement) and https://github.com/aframevr/aframe (A-Frame WebXR support).
